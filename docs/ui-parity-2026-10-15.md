# UI capability and visual review — 2026-10-15

The comparison uses upstream `rc` (`d57fa30`), especially `bower.json`, `app/static/index.html`, the Angular route table, signature controller/templates, dashboard, profile, files and test-history views. Screenshots of the React interface were captured before changing it and after the pass under ignored `output/playwright/`.

## What the original controls were

The original application used Angular UI Select 0.19.x, Bootstrap 3.3.7 and ng-tags-input 3.2.x. Record forms, inline state/owner controls and filters used searchable UI Select controls. Global search explicitly selected the `selectize` theme. Tags supported removable chips, suggestions and paste. They were not ordinary native select menus or comma-separated text fields.

The initial React migration substituted native selects, text fields and plain textareas while bringing up the new frontend. That was an incomplete migration: it lost useful interactions. Those omissions were not justified feature removals.

## Visual and scrolling changes

Black and white remain the base colors; red is the primary/action accent. Green branding and the remaining green browser theme color were removed. Status chips use restrained neutral/red tones. Buttons and icons share consistent sizes and alignment. Row actions remain visible without requiring hover.

Table headers and pagination stay available while the table scrolls. The table region is keyboard focusable. On narrow screens, pagination occupies two compact rows so previous/next controls do not fall outside the viewport. Tables scroll horizontally within their region rather than widening the page. Dialog headers, tabs and action footers stay in place while the body scrolls. Dropdowns and tag suggestions remain inside the viewport. Expanded dialogs and long code use their own scrolling regions.

No promotional or explanatory filler was added to the product.

## Deliberate presentation changes

- Angular UI Grid and its old plugins are replaced by semantic React tables. Filtering is in the toolbar/advanced-filter builder, with removable filter chips. Search, sorting, pagination, column visibility, persisted table preferences, bulk actions and inline state/owner editing remain.
- Bookmarks are named **Following** and have a dedicated destination. Administrative definitions are grouped in **Configuration** tabs. Import/export and the whitelist also have direct destinations. These workflows were moved rather than removed.
- The old file tree is presented as a sample list plus folder/group controls. Paths, file downloads and scoped folder/group deletion remain available.
- Word wrap uses the editor’s **Wrap** checkbox. The old application intercepted Ctrl+W for wrapping; the replacement leaves that browser tab-closing shortcut alone. Ctrl/Cmd+S saves, Ctrl+Q closes the artifact editor and Escape observes unsaved changes.
- DFI processing remains the explicitly accepted optional exclusion documented in the earlier review; its opt-in adapter was not removed by this UI pass.
